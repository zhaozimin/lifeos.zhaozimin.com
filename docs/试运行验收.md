# 七天试运行验收

观察窗从部署者确认启用起连续计算七天。
各解析版本分别记录起止日期，具体日期仅存私有验收。
新旧解析规则分开统计；原话重放另列，不冒充新增样本。
不足七天时，不宣称持续使用验收通过。

微信与网页均可记录；本观察窗只验收微信采集。
本机历史已迁移，历史导入与网页补录不计入微信解析样本。

## 使用方式

- 时间：可直接说开始活动，或给出已发生的起止时间。
- 只有时长而无锚点时，回答一个起止钟点。
- 收支：写金额、用途与真实资金账户；支付方式可另说。
- 灵感、日记与感受直接说，当前保存数据库原话标签。
- 直接提问或继续追问；最新版本使用最近八轮回答。
- 日期不属于今天时，明确写日期。
- `今天`：查询当天汇总，不调用模型。
- `撤销`：撤销上一条记录消息生成的全部账目。
- 需要补充信息时，在微信回答机器人的追问。

金额使用整数分。不同币种分别汇总。
新版微信新记账只接人民币，不自动换算外币。
原话保留；撤销只标记账目，不删除原话。

## 验收范围

验证密码与TOTP登录、收支入库、时间切换和微信回执。
验证CLI调用、格式纠正重试、异地备份和隔离恢复。
程序测试与合成模型探针分别记录，不充当真实使用样本。
真实金额、活动时段、原话和回执只保留私有验收记录。
公开文档不分发个人样本，也不将原始样本改称合成数据。

## 每日核对

1. 对照本人微信发送记录与数据库原话。
2. 包含指令和不支持的消息，排除机器人自己的回执。
3. 对照起止、活动、金额、分类、真实账户及支付方式。
4. 单独列出待澄清、失败、未投递和重试条目。
5. 检查备份服务结果和私有 R2 新归档。

“解析成功”只表示结构通过校验。
准确性必须由原话与实际经历共同判断。
“投递成功”表示渠道接受，不表示用户已读。

## 通过标准

- 连续七天使用微信记录。
- 微信发送条数与去重后的原话条数一致。
- 人工核对的解析准确率不低于 95%。
- 撤销保持原话、账目和汇总一致。
- 失败原话保留，并可在修复后重放。
- 备份可恢复，私密读取仍受本人 AAL2 限制。

当前状态：功能已上线；持续使用验收按私有记录判断。
不足七天时，不宣称持续使用验收通过。
模型超时后应单独复验，并保留失败事实。
真人微信收件与问答质量仍需部署者核对。
