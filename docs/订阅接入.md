# 订阅接入

订阅是 LifeOS 工作台的一级领域，与时间、财务、健康、记录并列。
统一入口为/dashboard/subscriptions。
主页、统计、银行卡和设置复用SubOS原版。
订阅界面贴着一级栏铺满，自带侧栏即二级栏；宿主只下发亮暗模式，业务仍由原版API执行。

## 真源与网络

VPS应用位于/opt/lifeos-subscriptions。
唯一在线工作库为/var/lib/lifeos-subscriptions/subos.sqlite3。
服务使用独立lifeos-subscriptions用户。
HTTP只监听127.0.0.1:18787。

浏览器同源请求先通过LifeOS本人AAL2。
Pages调用内部Worker服务绑定。
内部Worker通过固定VPC服务访问VPS。
出站Cloudflare Tunnel不创建公开域名或入站端口。
私有Worker关闭workers.dev和预览地址。
固定目标、方法和路径白名单拒绝任意URL代理。
Cookie和Origin不传入订阅源站。
浏览器不能配置VPS图像服务密钥。
图像AI在本机原本未启用，不新增Key或调用费用。

参考：[Cloudflare私有服务](https://developers.cloudflare.com/workers-vpc/configuration/vpc-services/)。
Workers VPC当前处于beta，接入版本写入部署记录。

## 数据迁移

迁移前停止本机写入并创建SQLite一致快照。
保留本机原始数据库和原自启配置。
迁移完整表、主键、账号、支付绑定和提醒历史。
被引用卡面随数据库一起核对。
逐表比较列、行数和完整数据摘要。
VPS开始服务前必须与快照完全一致。
订阅分钟结算使用Asia/Shanghai日期。
结算是本地账面计算，实际付款仍由原服务商执行。
不会因为部署而自动创建LifeOS财务流水。

## 本机入口

原127.0.0.1:18787改由SSH转发至VPS同一端口。
本机原写入进程与旧自启任务停用。
新用户级任务为com.zimin.subos.lifeos-tunnel。
旧URL仍可使用，读取和修改同一份VPS账本。
电脑关机仅影响该本机入口，云端仍正常运行。
本机旧账本是迁移前副本，不做双向同步。

## 备份

独立订阅备份使用既有私有R2桶。
前缀为subscriptions/，与主数据库备份分开。
每日北京时间02:10执行，保留30天。
SQLite与被引用卡面构成一个一致恢复单元。
归档使用既有age公钥加密，再核验R2字节与摘要。
Tunnel令牌和可选图像密钥不进入数据归档。
恢复验收逐表核对完整数据，逐文件核对图片字节。
R2配置只交给短时root备份进程。
订阅应用用户不持有R2配置或Supabase管理密钥。

## 功能边界

保留原版双模式、余额、充值、暂停和恢复。
银行卡只保存末四位和管理元数据。
浏览器保留原版7/3/1天通知及领取回执。
VPS另在扣款前7天发送微信提醒，电脑关机仍执行。
每天北京时间09至21点整点检查，首轮为09点。
只选生效、自动续费且金额大于零的订阅。
微信按订阅和续费日期去重，不消耗浏览器提醒。
渠道确认后才记送达，失败重试，当日文案不跨日发送。
提醒不生成实际付款或财务流水。
安装与上下文约束见../ops/subscription-reminders.md。
微信新增订阅指令尚未写入管家工具契约。
本次没有向MemOS批量上传订阅或支付信息。
