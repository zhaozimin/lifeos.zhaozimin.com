# 安全审计摘要

本轮61项匿名检查未取得受限数据。
网页112项及数据库65项测试通过。
该结论只覆盖本次范围，不代表不存在漏洞。

## 已检查的边界

- 匿名访问私人账目、原话、附件和导出被拒绝。
- 伪造Cookie、权限头和无签名JWT不能取得私人数据。
- 访客入口不接受私人方法、路径或写入。
- 已知publishable key不能读取私人表或调用私人RPC。
- 私人底表启用RLS，本人策略要求AAL2。
- 构建资源未发现密钥特征或source map。
- 私有备份不提供公开下载入口。

## 已实现的保护

本人访问采用密码与TOTP。
公开投影在服务端移除敏感字段。
HTTPS、HSTS和安全会话Cookie保持启用。
认证入口先检查内部限流，再恢复会话。
限流服务故障时拒绝放行，不降级绕过。

Cloudflare原生限流按节点近似计数。
它不提供全球硬上限，也不能代替MFA。
计数边界见[Cloudflare官方说明](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)。

隐藏登录链接只改变导航。
前端路由与接口仍可被发现。
权限必须由服务端和数据库执行。

生产依赖的已知公告已检查。
fflate使用0.8.3补丁，当前仅调用压缩导出。
主站与订阅生产依赖审计均为零项已知公告。
公告状态会随时间变化，发布前应重新检查。

## 部署者责任

使用独立SSH密钥，收紧管理入口与端口。
妥善保存TOTP、解密私钥和恢复资料。
不要在Git、截图或公开日志中写入私人信息。
公开时间、健康与订阅名称可被访客保存与分析。
需要降低公开范围时，应修改公开投影。

本轮没有执行大规模口令穷举或平台内部审计。
本人真实密码加TOTP重新登录不属于本轮自动验收。
AAL1及异主边界由合成测试和RLS审查覆盖。
完整风险清单保留于本机.private/github-release/docs/。
