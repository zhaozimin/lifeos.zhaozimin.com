# 本机数据迁移与网页编辑

本次执行一次完整迁移，不建立双向同步。
迁移后的网页编辑写入 Supabase。
本机程序和数据库保持原样。
迁移清单记录源快照时刻和各表行数。

## 数据保真

- 使用 SQLite backup API 读取三套一致性快照。
- 只读 time、finance、tasks 的正式数据库。
- 不把审计快照、备份库当作新增账目。
- 原始行、设置和旧审计保存在私有来源档案。
- 时间优先使用已冻结的 UTC 锚点。
- 没有偏移的财务时间使用旧账本时区。
- 金额用 Decimal 转为整数分，保留负数和零。
- 分类保留历史名称与性质，不强行套用新名称。
- 转账保留两端账户，不计入收入或支出。
- 扣减独立保存，跨日分摊沿用旧账本规则。
- 进行中时段保留空结束时间，不伪造收尾。
- 已删除记录保留删除标记，不计入统计。
- 任务计划保持独立，不伪造成实际时间。
- 账户、项目、任务组和附件保留原始标识。
- 附件使用本人 AAL2 下载；不生成公开链接。

## 网页编辑

本人密码与 TOTP 登录后才可编辑。
Worker 校验同源请求，数据库再次校验本人 AAL2。
网站继续使用 publishable key，不使用管理员密钥。
只能通过受限事务 RPC 修改指定字段。
原话、来源快照、归属和原始编号不能改写。
每次修改保存前后版本，并递增版本号。
旧版本提交必须返回冲突，不能覆盖新修改。
时间编辑支持活动、分类、起止、扣减、项目和备注。
收支编辑支持标题、金额、币种、分类、账户和备注。
转账编辑单独显示两端账户。
任务与账户提供各自的人工编辑入口。
重新导入同一源编号不得覆盖网页修改。

## 验收证据

- 导入前后核对原始行数、活跃行数和删除行数。
- 按币种与方向核对整数分合计。
- 核对时间毛时长、扣减和净时长。
- 比较跨日统计、进行中时段和任务归属。
- 重复导入不增加行数，不覆盖人工修改。
- 验证匿名、AAL1、异主和跨站不能写入。
- 正式站查看真实历史，并验证编辑和修改记录。
- 导入后创建 R2 加密备份并隔离恢复。

## 交付结论

生产迁移和人工编辑已完成。
逐行档案、逐字段投影和附件字节核对通过。
重复导入不新增账目，也不覆盖人工修改。
编辑演练已恢复原值，修改版本继续保留。
权限与隔离恢复检查通过，暂存表在事务内移除。
精确快照时刻、账目数量、时长和账户统计仅存私有验收。
