# 时间分类人工整理

用户要求先拿到HTML，自行整理后返还。
原始交付阶段不自动决定统计口径。
本人已返还HTML，现仅采用填写的大类。
细类空白和确认未勾不阻止本次导入。
夜间与午睡均按WHOOP校准，见时间分类与睡眠规则.md。
新大类、新细分类和确认状态初始全部留空。

## 数据覆盖

本机权威库为已安装LifeOS的time.sqlite3。
本机与云端时间段按来源编号去重。
覆盖活跃行、软删除行及全部原始事件名称。
具体行数、类别数量和快照哈希仅存私有验收。
本机与云端类别按稳定code合并。

同一code合并展示，双方原定义分别保留。
保留停用定义、原关键词和原性质。
本机原始时间行保存在localOriginal。
云端行保留修订号和快照哈希。
本轮没有读取财务交易或向外上传这些时间记录。

## 整理方式

按事件整理：同名事件共用一项批量规则。
全部时间段：逐条查看钟点、原分类、备注和项目。
类别字典：定义旧类别到新分类的映射。
映射仅在本人点击后应用到尚未填写的记录。
逐条规则优先于同名批量规则。
同名“休息”不能证明每次都属于同一种活动。
原始事件名称、原分类和时间均不可在此页改写。

原始模板的确认按钮要求同时填写大类和细类。
该限制不适用于本人本次授权的大类导入。
可自行新增大类，细分类使用自由文本。
可以只整理部分内容，再保存并稍后继续。
默认隐藏软删除行，勾选后可以查看。
筛选和分页不影响导出范围。

## 保存与返还

页面不依赖网络、外部字体或第三方脚本。
浏览器暂存只用于减少误关损失。
暂存不代替可携带文件。
点击“保存可返还的HTML”生成包含草稿的新文件。
重新打开下载的HTML即可继续填写。
也可导出JSON，之后导入同一批数据的整理页。
返还下载的HTML或JSON，不能只返还截图。

JSON格式为lifeos-time-review-result/v1。
原始快照标识为datasetId，防止混入另一批数据。
确认标记表示本人已确认分类，不表示已改数据库。
返还后先核对快照和云端修订，再准备正式应用。
发生并发修改时，不能用旧整理文件覆盖新记录。

模板为ops/time-review.html，不含真人数据。
生成器为ops/export-time-review.py。
真人文件位于本机LifeOS的reviews私有目录。
本轮不发布到Cloudflare或其他公网位置。
