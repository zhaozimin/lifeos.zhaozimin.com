# 时间分类与睡眠规则

2026-10-26：本人确认仅使用大类。
夜间睡眠和午睡均以WHOOP为准。
返还HTML的大类有效，空细类和未勾确认不阻止导入。

## 十一个大类

| 大类 | 范围 |
| --- | --- |
| 工作 | 课程、创作、剪辑、代码、业务和本人选定的设备事务 |
| 学习成长 | 本人归入学习的阅读与技能练习 |

| 私人社交 | 私人聊天、聚会和陪伴 |
| 出行 | 通勤、交通与步行移动 |
| 待确认 | 本人保留的模糊事件及等待WHOOP的睡眠 |

同名事件先匹配本人返还的精确规则。
“休息”“休息一下”归清醒休息。
“休息一会儿”“歇一会儿”归娱乐。
“回笼觉”“眯一会儿”按本人表归清醒休息。
WHOOP确认睡眠后，实际睡眠区间覆盖自述分类。
设备、网络、账号和Kindle事务沿用本人的工作选择。
不因活动名称出现“视频”而归娱乐。
三种原始模糊名称继续归待确认。
模型对新名称依照大类定义判断，不创建细类。

## WHOOP睡眠

只使用SCORED睡眠，包含nap=true的午睡。
实际睡眠毫秒数等于浅睡、深睡和REM之和。
WHOOP会话中的清醒与缺失数据不计入实睡。
接口没有逐阶段时间点，不编造清醒片段的位置。
时间轴保留WHOOP会话边界，以扣减表示非睡眠时长。
分钟账本对每次实睡向下取整；毫秒总量单独保留。
没有设备评分时，自述睡觉标记等待WHOOP，归待确认。
普通清醒休息保留原有大类，不推断为睡眠。

本人记录22点睡觉，WHOOP零点开始：22点到零点记刷手机。
WHOOP8点醒，本人9点结束睡觉：8点到9点记刷手机。
刷手机归娱乐，界面标明“本人规则推定”。
该规则不是手环检测到手机使用。
只在本人已记录的睡眠、休息或娱乐边缘推定。
不在未记录空白中补造手机活动。
工作和生活自理被睡眠覆盖时，区间外仍保留原活动。
WHOOP会话内部的清醒不推定为刷手机。

睡眠卡片按北京时间醒来日期汇总。
日时间轴和大类图按北京时间自然日切分。
跨午夜时，两种日期口径的单日数值不同。
工作时长只合计“工作”，不混入学习和出行。

## 数据与重算

分类导入核对当前活动名及修订号。

被睡眠替代的原始时间行软删除，修改版本保留。

每30分钟发布健康副本后执行同一校准事务。
相同载荷重复同步不新增时间段。
设备修订先校验旧生成行，再恢复原行并重新拆分。
正常起床后的活动切换保留新的结束时间。
其他人工改动导致冲突时保留改动，面板提示核对。
WHOOP实睡行禁止手动改变边界、活动和时长。
备注可编辑；后续设备修订不会覆盖该人工修改。
修改设备睡眠应先到WHOOP更正，再同步。
