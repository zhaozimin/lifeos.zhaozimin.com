# 访客访问契约

默认访问以访客身份浏览。
本人入口位于/dashboard/login。
访客页面不显示登录链接；本人手动输入地址。
隐藏入口不作为权限边界。
密码、动态码及首次设置共用认证限流窗口。
密码及动态码通过后挂载本人数据。
权限变化时重建页面树，清除旧页面内存。

| 内容 | 访客范围 |
|---|---|
| 时间 | 大类、起止时间、时长和统计 |
| 健康 | 六个原版页面、设备指标和公开计划 |
| 财务 | 原版三页、筛选、图表钻取和脱敏流水 |
| 财务金额 | 接口返回null；页面显示•••• |
| 银行卡 | 不提供实际卡片、卡号和卡面 |
| 订阅 | 原版卡片、品牌logo、侧栏、统计和只读详情 |
| 订阅价格与账号 | 固定显示•••• |
| 原话、备注与历史修改 | 不提供原文 |
| 新增、修改、删除与同步 | 不允许 |

时间标题默认使用大类名称。
时间页标题旁常显“日视图／周视图”，窄屏和收起侧栏仍可切换。
周视图按周一至周日显示七列，可切换上一周和下一周。
活动原始标题由独立配置显式开放。
公开健康数据固定使用北京时间。
原始设备ID不进入公开健康副本。
公开计划仅依赖公开指标和默认偏好。
本人计划、自述和身体限制不进入公开响应。
生活记录只保留日期，私人字段显示••••。
健康设置展示只读表单，不公开私人偏好。

财务投影只读取日期、方向和通用分类。
流水编号转换为不透明编号。
金额、账户、商户、项目和标题原文不进入投影。
前端使用固定示意单位维持原版图表结构。
金额标签、比例、坐标轴和提示框显示••••。
示意图不代表真实金额、比例或走势。
页面明确说明此边界。

订阅目录不选择价格、账号和支付绑定。
名称内的邮箱、网址和长号码再次脱敏。
公开编号使用单向散列。
品牌logo只从固定供应方读取。
图标入口不接受网址，不读取自定义图片或卡面。
原始网址、账号参数和支付绑定不进入响应。
旧版五字段目录保留，完整卡片使用v2目录。

公开接口统一位于/api/visitor/。
接口使用独立匿名客户端，不继承本人JWT。
时间、睡眠和财务RPC只读取固定站点归属。
时间范围不超过一年，不接受归属参数。
财务投影最多返回最新5000笔有效流水。
健康公开副本在VPS生成后再写入数据库。
访客无私有底表和本人发布副本的读取权。
订阅公开目录通过SQLite只读连接生成。
所有私有API继续要求本人AAL2。
响应使用no-store，避免公开与本人缓存混用。

visitor_settings仅有站点槽位1。
enabled为false时，公开数据接口停止供数。
share_activity_titles默认为false。
两项配置只由service_role修改。
数据库版本为0025。
正式Pages版本记在本机私有部署凭据中。
认证限流是每节点近似窗口；边界见安全审计.md。
验收记录见部署记录.md。
