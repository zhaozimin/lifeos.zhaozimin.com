# 部署摘要

主站由Cloudflare Pages托管。
Pages Worker持有发布密钥与本人会话。
浏览器不持有管理员密钥。

VPS运行微信传话筒、WHOOP和订阅服务。
健康与订阅服务只监听回环地址。
订阅通过内部Worker和私有Tunnel访问。
不要为内部服务创建公开入口。

Supabase保存原话、账目、回答及健康副本。
全部私有读取要求本人AAL2，底表不向匿名开放。
访客使用固定归属的只读投影，不继承本人Cookie。
密码、动态码及首次设置共用内部限流窗口。
财务公开响应移除金额、账户及私人说明。
订阅公开目录不含价格、账号和支付绑定。

网站使用HTTPS、HSTS和HttpOnly会话Cookie。
异地备份先加密，再上传私有对象存储。
解密私钥只保留本机，不提交Git。

原版时间、财务、健康和订阅页面已接通。
游客时间页常显日周切换，桌面、390px窄屏及侧栏收起状态均已验证。
订阅七天微信提醒已启用，VPS每天09至21点整点检查。
提醒测试已获得微信发送成功回执，浏览器通知独立保留。
微信单条时间纠错已上线，修改前后回执和冲突保护撤销已接通。
160项自动测试及6类实际模型路由通过，生产纠错和撤销演练已回滚。
Git分发不包含生产地址、资源编号或真实运行记录。
完整部署日志已转存本机.private/github-release/docs/。
