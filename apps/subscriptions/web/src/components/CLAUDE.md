# web/src/components/
> L2 | 父级: ../CLAUDE.md

成员清单
BrandMark.tsx: 品牌标。button 打开站点。所有标坐不透明 iOS 方板，影子跟方板走。商店方图铺满，其余居中。
icons.tsx: 边栏象形字。24 格 2px 方角线标，无外部库。FilterIcon 按分类 ID / 名称取标。选中色走 iconTone，未选中仍跟字色。含银行卡标；当前项图标用墨色，朱色只给已过期。
BankCardVisual.tsx: 标准银行卡比例的纯卡面。公开原卡图完整显示且不叠字；AI 图只作底图，银行名、卡名、尾号等准确字段由本地动态覆盖；被卡包与编辑器预览复用。
CardWallet.tsx: Apple Wallet 式层叠卡包。卡面本身直接触发编辑，不维护平行选中态；保留筛选空状态，不介入识别和持久化。
CardCoverPicker.tsx: 卡面来源编排边界。搜索/解析绑定请求身份，生成与解析期间阻止编辑器保存和关闭。优先编排照片脱敏生成，亦支持识别后搜候选、补关键词、点选缓存单图与官网 URL 末级兜底。
CardPhotoGenerator.tsx: 卡片照片隐私闸门。原图只在 Canvas 内裁切、去元数据并降成 32×20 色块；可在本机配置 Keychain，向 AI 只发 32×20 色块参考并先校验文本并接收无文字底图。
SubRow.tsx: 可排序订阅卡片。余额式显示余额圆环，自动扣款式显示到期圆环；充值和方式选择留在右侧设置面板。
BalanceSettings.tsx: 所有余额式订阅共用的侧栏入口。50、100、自定义充值及余额校准；通知父级提交状态，与方式切换互斥，重试沿用请求编号。
BillingModeSettings.tsx: 详情中切换即保存，编辑中只更新草稿。提交与充值互斥，结果和错误贴近控件，旧会话响应失效。
Sidebar.tsx: 订阅二级栏；去掉子系统品牌，与健康共用导航样式。保留分类、到期筛选和独立订阅设置。
Veil.tsx: 访客返回固定符号且禁止解锁； 分享遮罩。边栏「脱敏」滑块切换，账号溶成云雾。
CycleRing.tsx: 共用 8px 逆时针圆环。到期环常绿，不足 7 天黄、不足 3 天红。余额式足额时用「一、二、三」等中文整数居中显示月数，不带「月」字并填满金圈；不足一期时显示余额及比例缺口。未知为「—」，零费用为「∞」。扣款式保留倒计时。
FadeSwap.tsx: 换场。token 变了先淡出再淡入。主列换页、换分类用它。
EditorSheet.tsx: 路由控制的右侧 Sheet，进出完整动画。
PauseDialog.tsx: 暂停前问一句剩余期限留不留——留就是立即冻结天数，不留就是放弃剩余天数；到期不续由取消状态表达。只回传选择，不发请求。
SpendChart.tsx: 未来 12 个月预计扣款图。移到月份列上看金额。
ui/sheet.tsx: 右侧 Sheet。
ui/dialog.tsx: 居中短表单弹窗。
ui/select.tsx: 纸面下拉。不放箭头、不画滚动条；列表超出时边缘淡出。
