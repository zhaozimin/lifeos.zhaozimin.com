# Product

## Register

product

## Users

赵子民本人。深夜发现又被扣了一笔钱之后打开，想立刻看见「这周还有谁要伸手」，也要知道自己到底有哪些实体卡与虚拟卡。单人使用；账本迁入VPS，通过LifeOS密码和TOTP访问。不是财务记账员，也不给团队用。

## Product Purpose

SubOS是私人订阅承诺时钟。它记录你会反复付钱的东西：网站、金额、周期、支付方式、账号，并按下次扣款日倒数。成功标准：打开首页 3 秒内能回答「一共多少钱、最近要扣哪几笔」。走势和累计进统计页，首页不堆账本。

银行卡是同一本账本的支付工具资产。一张卡只录一次：实体/虚拟、发卡机构、信用/借记/预付、卡组织、末 4 位、币种、有效期、账单日/还款日与正常/冻结/注销状态。这份记录同时是订阅可选的支付方式，不造第二份重复数据。

末 4 位不含 BIN/IIN，不能用来推断发卡行或卡组织。SubOS 提供两种确认式识别：名称关键词完全本地；卡号识别允许输入前 8 位，或在浏览器输入态从完整号码截取前 8/末 4 位。请求只把前 8 位发送给固定 BINLIST 端点，服务端拒绝其他长度，识别结果必须由人确认；BIN 和完整 PAN 都不持久化。

公开 BIN 数据最多给出发卡行、官网、卡组织和产品候选，不能唯一决定真实卡面。Apple Pay 的卡面来自发卡行/卡组织的令牌配置，不是客户端按卡号猜图；同类消费者卡片管理产品也普遍依赖受控目录与用户选卡。SubOS 采用可替换的图片搜索提供方：有 `SUBOS_BRAVE_SEARCH_API_KEY` 时走 Brave Images API，否则走 DuckDuckGo Images 兼容回退。识别后用发卡行、产品、卡组织和官网自动取最多 8 个候选，官网域名与标准银行卡比例优先；用户也可补关键词重搜。候选不落库，只有点击选中的单图才进入原有 HTTPS 安全下载与内容寻址缓存。无法确认时仍保留官网卡片页 / 图片 URL 入口。

用户持有实物卡时，另一条确认式路径是照片重绘：原始 File 只进浏览器 Canvas，居中裁切、去元数据并先降为 32×20 色块；服务端只允许32×20、经 PNG 校验与去元数据的色块参考，再交给 GPT Image 生成无文字、无账户信息、无防伪仿制的原创底图。最终只有 AI 结果进入本机内容寻址缓存；发卡行、卡名、末 4 位和卡组织由本地 UI 动态覆盖。API Key 只来自环境变量或 macOS 钥匙串，不进 SQLite。

所有分类的订阅都支持余额式和自动扣款式。右侧详情中选择方式即保存；编辑中随草稿保存。控件旁显示结果或错误。两种方式均支持月、季、年和自定义天数。切换保留余额、支付绑定和当前状态，原支付不是正常信用卡时等待配置。

余额式以人民币余额支付每一期订阅费。未知余额不自动抵扣，首次录入不追扣未知历史。余额不足时保留余款并暂停；充值足够后扣除一期费用，从当天开启新周期。手动暂停不因充值恢复。金色圆环在足额时用「一、二、三」等中文整数居中显示可支付月数，不带「月」字并填满；不足一期时显示剩余余额及比例缺口。季、年分别按 3、12 个月换算，自定义按 30 天折月，均向下取整。未知余额显示「—」，零费用显示「∞」。充值与校准只在侧栏出现。

自动扣款式绑定正常状态的信用卡，到期更新本地续费记录，保留到期圆环。未配置信用卡或卡被冻结、注销时不自动推进。实际扣款由订阅服务商执行，SubOS 不发起交易。银行余额、流水、预算、信用额度与还款计算仍在 LifeOS / FinOS。

## Design Principles

- 朱标记操作与不足：用于「新订阅」、紧急到期和余额不足
- 分类是目录：AI、话费、网络必须一眼分开，不是筛选项的附属
- logo 是入口：商店方图加 iOS 26 连续圆角，点 logo 去品牌站，点行出 Sheet 编辑，背后毛玻璃
- 日期遵循保存方式：余额式抵扣一期再推进；自动扣款式绑定正常信用卡后按周期推进。暂停、取消或关闭自动续费时不自动推进
- 暂停不是取消：暂停冻住时钟、留着记录，随时能回来；取消是用到期末就结束。停的时候问一句剩余期限留不留——留就是立即冻结剩余天数，不留就是放弃剩余天数；取消不冻结，保留原账单日并从「已取消 / 结束」访问
- 提醒三波：正好提前 7 / 3 / 1 天各一次。钟在 SubOS，邮差可以是浏览器或 Hermes
- 本机封闭：只绑 127.0.0.1，账号只记标识
- 卡片最小化：只记末 4 位和管理元数据；完整卡号、CVV/CVC、PIN、卡密与验证码在 API 边界就被拒绝
- 识别即焚：完整号码只可在浏览器输入态短暂停留；识别请求严格只发 8 位，完成立即清空，不把 BIN/IIN 写进数据库或日志路径
- 卡面确认式：BIN 只缩小搜索范围，不声称命中精确卡面；搜索候选不落库、不批量下载，只有用户点选的单图才进缓存。官网域名优先，内网、SVG、超大文件与不安全重定向不进缓存
- 照片最小披露：实物卡原图不离开浏览器；用户明确选择照片触发自动生成后也只发送不可读色块参考。AI 只画底图，正确文字留在本地，生成结果与原图语义上分离
- 注销优先于删除：卡不用了改状态，保留与订阅的语义链接；还被订阅占用时禁止删除

## Accessibility & Inclusion

对照 WCAG 2.2 AA。正文字色对比 ≥ 7:1；状态不只靠颜色（过期/今天/将到期都有文字）。尊重 `prefers-reduced-motion`。倒计时数字使用 `tabular-nums`。
