工作台外壳：一级栏切领域，二级栏切领域内页面，内容区显示页面。
二级栏骨架恒定：56px 标题 → 导航 → 底部日期插槽；五个领域的导航起点与日历位置像素级一致。
内容区自适应铺满，左右边距 40，最宽 --lifeos-content-max（1440）后居中；宿主、健康与订阅的内容左右缘一致。
订阅自绘二级栏并复用 sidebar.css；健康由宿主画二级栏，iframe 只显示内容。
领域设置留在所属领域。LifeOS 设置只承载全局选项。

成员清单
domains.ts: 领域、页面图标和独立设置入口真源；embedded 表示 iframe 内容区铺满，ownSidebar 表示自带二级栏（仅订阅）；路径换算领域与页面标题。
Rail.tsx: 桌面一级栏和窄屏底栏；访客不显示登录入口，本人显示退出。
DomainSidebar.tsx: 二级栏骨架（标题、导航、底部日期插槽）；时间今天页附来源筛选；领域设置选项在本领域展开。窄屏按组分行，菜单消费 settingsNavFor。
SidebarSlot.tsx: 页面把日期面板投放到二级栏底部插槽的唯一通道；范围状态仍归页面，侧栏收起或窄屏时退回内容区顶部的折叠条。插槽为空（设置、收件箱）时显示同高的只读今天月历。
RangePanel.tsx: 全领域共用日期面板：单字范围键（日 周 月 季 年 全 区）+ 月历 + 两行说明；高度恒定，点日期＝选中它所在的那一档。
shell.css: 一级栏键（当前领域朱色淡底朱色图标）、名称签与二级栏节标签；不重复定义导航行。
sidebar.css: 宿主与订阅共用侧栏，并定义内容区最大宽度 --lifeos-content-max；固定 266px、56px 标题、36px 图标行（当前行朱色淡底朱字）与底部日期插槽。订阅 iframe 在 640px 以下转顶部导航。
