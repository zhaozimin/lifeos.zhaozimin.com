# styles/
> L2 | 父级: ../CLAUDE.md

附加页（登录、历史记录、原话收件箱）的样式，全部限定在 .cloud-legacy 内。
按钮用 .zzm-btn，输入框用 .field；本目录不再写控件外观，只写版式。
颜色、阴影、圆角一律取 --zzm-* 令牌。

成员清单
base.css: 共享排版、卡片、标签胶囊、空状态与错误条。
records.css: 历史检索、记录列表、分页与编辑对话框；编辑框沿用确认窗语法，手机表单单列。
inbox.css: 原话收件箱的说明条、筛选条、原话卡与解析状态徽章。
auth.css: 密码与验证器登录页；整页唯一朱色落在标题「轨迹」。
